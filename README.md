## 🛠️ CARA PENGGUNAAN

### Mode Simple
```python
from smart_agent import SmartAgent

agent = SmartAgent()
agent.train("video_transcript.txt")
results = agent.get_results()
```

### Mode Advanced
```python
from smart_agent import SmartAgent

agent = SmartAgent()
agent.learn_from_source("video", "contoh teks")
results = agent.evaluate_and_report()
```
